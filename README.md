# SheetForge

Windows Excel 工具，当前客户版 **v0.3.0**。

## 下载

[下载最新客户版](https://github.com/smallannsen-droid/SheetForge/releases/latest)

完整解压 `SheetForge-Windows-Customer.zip` 后双击 `SheetForge.exe`，无需 Python。加密 ZIP 的密码由交付方单独提供。

支持模板行插入、单元格更新、行删除、文字色/填充色/罫线设置、按当前文字色批量改色，以及文件夹递归批处理。可处理全部或指定工作表、行范围或单元格范围。筛选隐藏行也会改色，保留公式、太字、超链接和隐藏状态；条件格式可能覆盖显示颜色时会提示。

Windows 10/11 64 位及 Microsoft Edge WebView2。Excel COM 需要 Microsoft Excel；没有 Excel 时可使用 openpyxl 处理 xlsx/xlsm。默认另存 `_edited` 副本，可先检查变更计划。
